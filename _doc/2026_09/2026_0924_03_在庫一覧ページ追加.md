# 在庫一覧ページ追加

## 日付

2026-09-24

## 作業概要

特徴ページ内にあった「弊社在庫品」のリストを独立したページ（`/stock/`）にし、グローバルメニュー・フッターに「在庫一覧」を追加した。あわせて、リストの見やすさ改善（PC 2 列表示、番号の太字）を行った。

## 1. 在庫一覧ページの新規作成

### 方針

| 項目 | 内容 |
|---|---|
| 新ページ | `src/pages/stock.astro`（URL: `/stock/`） |
| 移したもの | features の「弊社在庫品」セクション（リスト 31 項目、更新日、問い合わせ案内） |
| features に残したもの | 「自社倉庫保有の在庫力」の説明と倉庫画像 4 枚 |
| メニュー位置 | 「導入実績」の次（トップ / 特徴 / 導入実績 / **在庫一覧** / 買取 / 会社概要 / よくある質問 / お問い合わせ） |
| ヘッダー画像 | `public/assets/images/header_stock.jpg`（3000×400。当初は `header_features.jpg` を仮利用し、画像追加後に差し替え） |
| スタイル | 既存の `p-purchase-info` を再利用 |

### 変更ファイル

- `src/pages/stock.astro` — 新規。title は「在庫一覧 | 株式会社ミエフソー | 製材機械の再生品、中古品の販売」、description も設定。更新日の `id="updateDate"` は不要のため外した
- `src/pages/features.astro` — 在庫リストのセクションを削除。在庫力の説明文の下に「現在の在庫機械は、在庫一覧をご覧ください。」のリンク文を追加
- `src/components/common/Header.astro` / `Footer.astro` — 「在庫一覧」を追加
- `src/pages/projects.astro` — 在庫情報のリンク先を `features#stockList` から `/stock` に変更
- `src/pages/purchase.astro` — 更新日の `id="updateDate"` を削除（使用していないため。ユーザーが編集）
- `public/assets/images/header_stock.jpg` — 新規（ユーザーが追加）

### 備考

- 「INC-900 センタードック 本自動送材車」は正しい名称のため、そのまま（誤字ではない）。

## 2. 在庫一覧の見やすさ改善

### 課題

PC 表示でリストが 1 列（幅 42%）で、31 項目が縦に長くなり、スクロールが必要で見にくいという指摘があった。

### 対応（`src/assets/styles/page/_purchase.scss`）

- `stock.astro` のセクションに修飾子 `p-purchase-info--stock` を追加（買取ページの `ol` に影響させないため）
- 全幅: 項目の上下余白を 16px+16px から 8px+8px に変更
- 1024px 以上: 幅を 90%（最大 `$container-width-pc` = 1044px）に広げ、`column-count: 2`、`column-gap: 48px` の 2 列表示。項目の途中で列をまたがないよう `break-inside: avoid` を指定
- 1024px 未満: 1 列のまま

### リスト番号の太字

- `p-purchase-info ol li::marker { font-weight: $fw-bold; }` を追加
- 当初は在庫一覧のみとしたが、「現在探している機械」（買取ページ）も同様にしたいとの要望で、共通の `ol li` に移した。対象は買取ページと在庫一覧の両方

## 確認

- `npm run lint:css` エラーなし、`npm run build` 成功（25 ページ）
- ユーザーによるブラウザ確認済み
  - PC 幅でメニュー 8 項目が収まる
  - スマホの開閉メニューに「在庫一覧」が表示される
  - `/stock/` でメニューの現在ページ強調（`is-active`）が付く
  - 2 列表示・番号の太字

## 残対応・確認事項

- 在庫リストの更新日は、`stock.astro` と `purchase.astro` とも固定表記（`2026/9 更新`）。更新時は手動で書き換える
- 在庫が増えた場合は、カテゴリ別の見出しでの分類（帯鋸盤・送材車・チッパー等）や、表形式への変更も検討できる
- 2 列表示では、左列の最後の項目にだけ罫線が付く（気になる場合は調整）
- コミット（ユーザーが実施）: 「在庫一覧ページを追加し、メニューに掲載。リストを2列表示に変更」
