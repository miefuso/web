## 2. `index.astro` 5 行目の型エラー対応

- 内容: `import '@splidejs/splide/css';` に VSCode で `ts 2882`（副作用 import の型宣言が見つからない）が表示されていた。
- 原因: Astro 拡張機能側で副作用 import の検査（`noUncheckedSideEffectImports`）が有効になっており、`.css` で終わらない名前の CSS import が型宣言に一致しないため。ビルドや動作には影響しない。
- 対応: `src/env.d.ts` を新規作成し、型宣言を追加した。

```ts
declare module '@splidejs/splide/css';
```

- 補足: `/// <reference types="astro/client" />` のみでは解消しなかったため、この形にした（`astro/tsconfigs/strict` が `astro/client` を既に参照しているため冗長）。
- 確認: VSCode の診断が 0 件になること、`npm run build` が通ることを確認。
