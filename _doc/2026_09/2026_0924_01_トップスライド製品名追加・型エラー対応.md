## 2. `index.astro` 5 行目の型エラー対応

- 内容: `import '@splidejs/splide/css';` に VSCode で `ts 2882`（副作用 import の型宣言が見つからない）が表示されていた。
- 原因: Astro 拡張機能側で副作用 import の検査（`noUncheckedSideEffectImports`）が有効になっており、`.css` で終わらない名前の CSS import が型宣言に一致しないため。ビルドや動作には影響しない。
- 対応: `src/env.d.ts` を新規作成し、型宣言を追加した。

```ts
declare module '@splidejs/splide/css';
```

- 補足: `/// <reference types="astro/client" />` のみでは解消しなかったため、この形にした（`astro/tsconfigs/strict` が `astro/client` を既に参照しているため冗長）。
- 確認: VSCode の診断が 0 件になること、`npm run build` が通ることを確認。

## 4. 独自ドメイン公開時の CSS・画像が読み込まれない問題の対応

### 事象

ムームードメインで取得した独自ドメイン（`miefuso.co.jp`）を GitHub Pages に設定して公開したところ、DNS 設定は正しいのに CSS と画像が読み込まれなかった。

### 原因

`astro.config.mjs` の `base: '/web'` と、`_variables.scss` の `$base-url: "/web"` が、`https://miefuso.github.io/web/` で公開する前提の設定だった。独自ドメインのルートで公開すると、HTML は `/web/_astro/...` を参照するが、実ファイルは `/_astro/...` にあるため 404 になる。

### 対応

- `astro.config.mjs`: `site` を `https://miefuso.co.jp` に変更し、`base` を削除
- `src/assets/styles/foundation/_variables.scss`: `$base-url` を `""` に変更
- `public/CNAME`: 新規作成（`miefuso.co.jp`）
- `.astro` 内の `import.meta.env.BASE_URL` は、`base` を外すと空になるため修正不要

### 確認

- `npm run lint:css` エラーなし、`npm run build` 成功（24 ページ）
- `dist` 内に `/web/` を含むパスが残っていないこと、CSS が `/_astro/...`、背景画像が `/assets/images/...` を参照していること、`dist/CNAME` が出力されることを確認

### 公開後の確認事項

- GitHub の `Settings > Pages` で Custom domain が `miefuso.co.jp` になっていること、証明書の発行後に「Enforce HTTPS」を有効にすること
- `www.miefuso.co.jp` でもアクセスさせる場合は、DNS に `www` の CNAME（`miefuso.github.io`）を追加

## 5. 独自ドメインのメール（相談）

- 独自ドメインのメールを Gmail で使う方法として、Google Workspace（有料）の契約と、ムームーDNSへの DNS レコード追加を案内した。
