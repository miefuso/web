# アクセス解析導入

## 日付

2026-11-02

## 作業概要

サイトへのアクセス解析として、Google Analytics 4（GA4）・Microsoft Clarity・Google Search Console を導入した。3つを組み合わせ、「どれくらい見られているか」「どこで離脱しているか」「検索ワードは何で来ているか」を確認できる状態にした。

## 導入したツール

| 目的 | ツール | 管理画面 URL |
|---|---|---|
| どれくらい見られているか | Google Analytics 4（GA4） | https://analytics.google.com/ |
| どこで離脱しているか（ヒートマップ・録画） | Microsoft Clarity | https://clarity.microsoft.com/ |
| 検索ワードは何で来ているか | Google Search Console | https://search.google.com/search-console |

- GA4単体では検索ワードは分からない（Google が大半を "(not provided)" として隠すため）ため、Search Console が必須。
- Clarity は、Dead Clicks・Rage Clicks・Excessive Scrolling などの指標でページの問題箇所を見つけ、Heatmaps・Recordings で詳細を確認する。
